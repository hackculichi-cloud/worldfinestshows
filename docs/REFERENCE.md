# Visual reference and attribution

Reference: https://www.worldsfinestshows.com/, inspected October 26, 2026.

The first unverified red/cream proposal was superseded after access to the original site became available. This implementation follows the actual site’s identity and content order rather than that initial design.

Retained visual features:

- Navy header and ribbon logo with colourful stars.
- Roboto headings/body text, pink links/buttons, light-blue section backgrounds.
- Translucent navy hero text panel with circular Passes/Events/Attractions/Newsletter shortcuts.
- Multicolour section separators and carnival-skyline decoration.
- Mega Passes → Events → Attractions → Newsletter → Contact/footer order.
- Original carousel and slide photographs as full-width section backgrounds.
